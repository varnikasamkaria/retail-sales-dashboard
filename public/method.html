Data & Method

Data source

Kaggle. The final file used here is clean_data.csv: … rows and … columns, … to ….

🐍 Google Colab (Python / Pandas)

  1. Load and inspect: read the CSV, check shape, column names and data types.
  2. Missing values: count empty cells per column and fix or remove them.
  3. Duplicates: check repeated rows and repeated Sale_IDs and drop them.
  4. Data types: make sure dates are dates and quantity, prices and amounts are numbers.
  5. Consistency: make text values uniform (names, categories, cities, membership tiers) and check that Month matches Sale_Date.
  6. Calculated columns: create Calc_Revenue and Calc_Profit.
  7. Exploratory analysis: summaries and charts by month, store, category and product.

🗄️ MySQL Workbench (SQL)

  1. Import the cleaned data into a MySQL table.
  2. Check quality with queries for NULL values and duplicate Sale_IDs.
  3. Check data types of dates and numeric columns in the table.
  4. Analyse with GROUP BY queries for revenue, profit and orders by store, category, membership and month.
  5. Rank products by total profit.

MetricHow it is calculated
